# Sample Outputs Overview

This directory contains representative outputs from the ZentroMart VoiceOps evaluation pipeline.

## Included Files:
- `baseline_results.csv`: Results from the LLM-only baseline run, demonstrating high abstention rates when lacking policy access.
- `rag_results_v5.csv`: Final RAG pipeline results showing grounded responses with evidence citations.
- `baseline_vs_rag_v5.csv`: Direct comparison between baseline and RAG, used to calculate the Non-abstention and Abstention rates.
- `retrieval_evaluation_latest.csv`: Quantitative metrics for the vector index, including Recall@K and MRR.
